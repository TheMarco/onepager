Why a lens.

A Fresnel lens does not make light. It refuses to waste it. Hundreds of small prisms, each set at a calculated angle, bend stray rays into one parallel beam. Product judgment does the same thing with attention. Research, constraints, taste and code arrive from every direction. The work is to set each piece at the angle that sends it the same way.

AI widened the aperture. More light arrives than any one person used to gather: drafts, variants, prototypes, analysis. The keeper problem did not change. Keep the lamp trimmed, keep the prisms clean, and log what the weather actually did. The beam is only trusted because the log is honest.
