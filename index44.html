Bureau method.

A rotor machine never encrypts a letter as itself, and it never encrypts the same letter the same way twice in a row. Good product work has the same property. The same brief, run through research, constraints and taste, should never come out as the template it went in as. If your process returns the average answer, the rotors are not turning.

AI made encryption cheap and decryption cheaper. Anyone can generate traffic now. The scarce skill is cryptanalysis: reading a flood of plausible output and knowing which line carries the signal. That reading is the job, and it is learned the slow way, file by file.
